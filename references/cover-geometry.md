# 已确认封面构图

使用本文件的当前分类参数，耳坠和耳钉采用各自尺寸。

## 画布和坐标

所有封面为 **1600×1600 px，纯白背景**。坐标原点为左上角，底边y=1600。以下是画布像素，不是网页CSS像素。

主体范围指珠宝本身，不包含柔和阴影；耳饰是整对，单珠链饰是链与镶座/主珠整体。主珠下缘和整体下缘不是同一个测量字段。水平居中；除指定下缘外，圆环垂直居中。不得为了达到边界值拉伸珠子或变形首饰。

| 预设 | 构图 | 尺寸目标 | 垂直位置 |
|---|---|---|---|
| bracelet | 完整圆圈、搭扣可见 | 1000×1000范围 | 居中，理想范围x/y 300–1300 |
| necklace | 完整圆圈、搭扣可见 | 1200×1200范围 | 居中，理想范围x/y 200–1400 |
| drop-earrings | 一对并排 | 整对约750 px宽，等比缩放 | 珠子下缘y=1200，即距底400 |
| stud-earrings | 一对并排 | 整对约600 px宽，等比缩放 | 珠子下缘y=1000，即距底600 |
| pendant | V形链条，主珠在最下方 | 整体宽高均不超1200 | 主珠下缘y=1400，即距底200；顶部留白 |

耳饰不再强行把外框填满1000。耳环/其他设计按真实形态选择较接近的耳坠或耳钉预设；不能适用时给出有依据的单品例外供审，而不是默认为所有设计同尺寸。

等比构图例子：手链约974×1000；项链约1200×1175；耳坠约750×727、底400；耳钉约600×325、底600。它们说明**等比与真实形态优先于数学正圆**，不是后续商品必须照抄的宽高比。

封面视觉大小不是实物比例尺。不可暗示一对耳钉与项链的画面大小是物理尺寸可比；真实尺寸由产品信息与批准的尺度图说明。

## 几何清单

为每个文件填人工核对的像素范围，使用右/下不含端点的bbox：

```json
{
  "covers": [
    {
      "file": "sku-cover-v1.png",
      "preset": "stud-earrings",
      "bbox": [500, 675, 1100, 1000],
      "pearl_bottom": 1000,
      "review_status": "pending"
    }
  ]
}
```

用脚本检查数值与文件实际画布。脚本不会替你自动找边缘，也不会检测金属/珍珠是否被生成模型改变；不要把自己填的bbox当成独立视觉证据。发现不符合时调整并重新量测，或明确例外等待审核。±3 px仅用于像素测量/抗锯齿边缘容差，不用于宽泛放松构图。

# 产品对照尺子比例图

作为独立详情图片类型评估，不替代封面、珠光细节或三视图，不改变其他图片规则。

## 构图参考

构图参考为一段横向排列的珍珠，底部是一把水平毫米尺，白色背景；珠子与尺子均清晰可读。参考只说明“产品上方、真实尺子下方”的视觉安排，不能从截图直接认定任一SKU的实际珠径，也不要求所有商品改成十颗珠子。

- 珠串可展示真实的一段；耳饰或单珠展示实际单品。保持真实数量、结构与比例。
- 尺子放在产品下方，不遮挡主体，零点、毫米单位和连续刻度可辨；不以侧边直径箭头代替用户指定的尺子。
- 不为了统一正方形裁掉刻度或关键产品结构；本类型不另设强制1600方形规则。

## 来源与真实性

1. 优先使用产品和尺子原本就在同一张照片中的实拍，尽量同平面、正位拍摄，避免透视误导。保留两者之间的原始相对尺度，不能分别缩放产品与尺子后仍称实测。
2. 若只有产品实拍与可靠尺寸，可根据已核实尺寸制作比例示意。内部记录所用尺寸、来源与示意制作方式；前台可用中性“尺寸参考 / Size reference”，不默认添加AI或合成专门标签。图片和标注比例必须准确，不称实拍测量或精密实测；尺子外观逼真也不改变其来源性质。
3. 可靠尺寸应来自该SKU获确认的产品资料、证书或用户明确提供的数据。没有尺寸时列为缺信息，先完成其他图片。不要从另一款或参考截图猜尺寸，不把一个范围改成未经确认的精确值。
4. 单珠直径、镶座总高、吊坠总高与链长是不同尺寸；只呈现有依据的维度，不用珠径推算未知镶座或链条尺寸。非正圆珍珠也不能强制画成等径圆。

## 审核与交付

- 逐一人工核对尺子数字、单位、零点与刻度顺序；检查每厘米十个毫米间隔、刻度连续等距。AI图中的尺子不能只靠视觉像真就放行。
- 用已知尺寸核对产品相对刻度跨度；真实同框图若透视或模糊导致不能判断，只称“大小参考”，不能声称精密测量。示意图记录所用尺寸来源，核对相应像素/毫米比例。
- AI刻度或比例有误则返工，不通过修改产品事实来适配尺子。保留原始参考与派生版本；在内部制作记录中区分“同框实拍编辑 / 尺寸比例示意 / 待核验”。
- 出图后给用户审核，未批准不配置网站。证书遮号及其他既有规则不变。

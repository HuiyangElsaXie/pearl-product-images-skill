# 品牌视觉质量与场景指导

## 双重基准

原产品实拍负责商品事实；视觉参考负责光线、构图、材质呈现与美感。不可把参考图里的珠径、珠数、镶座或包装当成该SKU事实。每次先写“保持什么、改善什么”，不把“保真”误解为必须保留原照片的灰暗、偏色、杂乱背景或僵硬角度。

- 场景自由：在任务授权范围内可制作模特、礼盒与干净生活场景，不因没有完整原场景照而一律停工。真实产品结构仍以原图为依据；缺失的关键产品角度不凭空补造。
- 细节精致：保留细链、金属边缘和镶嵌轮廓的清晰连续性，清理杂乱反射但保留受控高光及自然阴影；不要呈现塑料感、污灰金属、熔化边缘或虚构划痕。
- 珠光通透：用柔和主光、自然明暗过渡与清晰高光体现圆润和层次，避免一片死白、粉笔哑光、污灰暗斑或夸张玻璃透明感。珍珠不是透明玻璃，不能通过增加透光、添加粉绿颜色或改变原色制造“高级感”。
- 模特自然：按品类挑选身体局部与视角，可参考自然侧脸与颈线的舒展构图，姿态不僵硬，肌肤保留自然质感；衣料及背景安静，留白服务主体。检查手部/耳部结构、佩戴接触和重力，不让链子穿皮肤或产品悬浮。
- 礼盒精致：正位俯拍、盒边端正、内衬柔和且有层次、产品摆放自然；可选灰蓝等低干扰色调衬托主体，不将此固化为所有产品唯一盒色。允许场景创作但不虚构实际包装承诺。
- 尺子可读：横放、近产品、明确测量目标，刻度可靠；只增加一个看似真实的尺子而无法读出关系不合格。

## 珠光精修：采用 B 版质感方向

构图和结构确认后，将珠光精修作为独立步骤，不用整体增亮代替材质塑造。B 版的取舍是“明确主高光 + 连续自然渐变 + 明暗层次”，不是采用其可能出现的暖香槟色。保留该件原始实拍的底色与真实伴色；白/银白珠不能因此变成奶油、灰金或香槟色，金珠也不能漂成白珠。

### 执行顺序

1. **锁定不变项**：对照原实拍和已批准基准，锁定珠形、大小、数量、镶座、金属色、构图与产品底色；只针对光线和珠光表现精修。
2. **建立高光主次**：给珠面清晰但不过曝的主高光，辅以更弱的次高光；高光边缘过渡柔和，亮部仍有细节。避免均匀涂亮、整圈白边、多个同强度光斑或一片死白。
3. **保留立体渐变**：亮部到中间调、暗部连续过渡，以真实曲面明暗表现珍珠质的厚度与圆润。不能靠玻璃透明感、金属球反射、人工颗粒或过度磨皮制造珠光；不能抹掉影响购买判断的实际表面特征。
4. **珠光与金属分开处理**：珠面侧重层次和柔和光泽，金属侧重干净连续边缘与受控亮点；不全图加锐，不增添磨损、污灰、熔化边缘，也不改粗镶爪或细链。
5. **光线服从场景**：白底、礼盒、佩戴图可有不同环境反射，但同一产品底色必须一致。成对耳饰光向协调，不能机械复制完全相同的高光图案。移除摄影者、手机等干扰反射时，保留自然光影逻辑。
6. **失败时回源图**：出现塑料感、色漂或结构漂移，回到原实拍及已批准基准调整，不在多轮失真结果上继续叠加。

### 可复用编辑提示词

> 仅精修参考产品的珠光，保持原有产品结构、珠形、大小、镶座、金属色和构图。严格保持原实拍的珍珠底色及可见伴色，不增加暖香槟色或虚构粉绿晕彩。形成清晰但不过曝的主高光、较弱辅光，以及从亮部到中间调和暗部的连续柔和渐变，呈现真实珍珠质的圆润与层次。去除杂乱人物/手机反射，保留自然曲面光影；不做均匀塑料涂层，不做透明玻璃或镜面金属球，不增加颗粒、磨损，不抹除真实产品特征。金属边缘清晰自然，不整体过度锐化。

### 珠光专项验收

与原实拍和批准基准并排检查缩略图及100%原尺寸，逐项记录 `pass / warn / fail`：
- 主高光明确、不过曝，辅助高光不抢主光。
- 亮/中/暗层次连续，圆润但无塑料、玻璃或金属球质感。
- 底色及真实伴色忠于该SKU，白平衡改善不等于改珠色。
- 珠形、表面特征、镶座与金属结构未变；珠光提升不以失真换取。
- 成对产品、同批图片光线协调，场景自然且不机械复制反射。

几何QA、实物保真和品牌质感分别验收；用户认可 B 方向只确定处理规则，不自动批准其他成图、网站替换或发布。未核验项不得写通过。

## 可执行审图

每张图按两层看：缩略图检查主体、留白、视觉焦点和整体光色；100%放大检查珠形、扣件、链边、金属、肌肤、尺子刻度与证书遮号。与原图和视觉参考并排比，不只凭“整体漂亮”通过。

几何QA与视觉QA分别记录 pass/warn/fail。视觉QA内分开记录：
1. 保真：结构、颜色、实际尺寸依据、配对及商品事实。
2. 品牌质量：自然构图、珠光层次、金属精致度、场景协调、清晰度。

明确失败例如：产品被改变、尺子刻度错误、珠光漂白、金属边缘融化、模特姿态/佩戴关系不自然、礼盒透视失真。警告例如：源图关键部位模糊，难以证明细节保真。缺陷要写出位置与下一轮修法，不能只给总分或“高级感不足”。

返工回到原实拍与已批准参考，针对问题修改提示词和场景设置，不连续叠加多轮AI图造成结构和颜色漂移。若用户要求完善skill，先更新规则；只有另行要求试跑时才生成图片。成图给用户审核，不自动配置网站。

# 礼盒、模特佩戴与证书图片操作流程

三类均以该SKU真实资料为依据，独立交付供用户审核；不改变封面构图，不自动上传或部署。

## 礼盒内正位俯拍

1. 两条路径均可：编辑该SKU装在实际礼盒中的实拍；或根据产品原图、已批准视觉参考生成礼盒场景。没有原礼盒图不自动阻塞场景创作；内部记录真实包装编辑或生成场景。
2. 正位俯拍：镜头正上方，盒体端正、内衬自然、产品居中有留白；选择衬托产品的低干扰盒色和柔和材质。产品结构、尺寸关系与真实摆放逻辑不变，不通过透视校正拉伸珠子。
3. 整理光线、自然提亮珠光和金属，保留盒内明暗层次与接触阴影；不把盒内统一抹白，不让产品悬浮。保留真实产品参考，不补造看不见的扣件或背部。
4. 若任务是展示实际随附包装，必须使用可验证的真实包装信息；若是生成展示场景，不新增品牌标识、赠品或包装承诺，不称其为实际赠送/交付的礼盒。内部记录场景性质，前台无需默认AI专门标签。
5. 对照产品原图检查珠形、颜色、珠数/配对、搭扣和镶座；另核验盒边透视、内衬质感、产品摆放和光影是否自然。仅产品保真通过而礼盒场景粗糙，不算成图通过。

## 模特上身 / 佩戴图

1. 优先使用用户指定的实际佩戴图，确认佩戴的是该SKU。保留原来的产品与身体相对尺度，不单独放大珍珠以突出卖点。
2. 可以调整曝光、白平衡、背景与裁切，保持产品结构、长度、垂坠位置及佩戴关系。不能将耳饰、链子或手链悬空、穿入皮肤或复制多余连接件。
3. 依用户隐私要求避免露脸或扩大遮挡范围；审核成图时放大检查眼睛等指定遮挡区域是否全部覆盖，不能仅看缩略图。
4. 任务已授权制作模特佩戴效果时，可依据产品原图生成合适模特场景，不要求先有完整实拍模特照；不将生成真人身份冒充原客户。根据真实产品图、已核实尺寸及可用佩戴参照安排比例；没有身体尺度参照时不宣称精确佩戴尺寸或效果。内部记录合成来源；不默认在前台专门标注AI或合成，使用准确中性的“佩戴效果”等描述，不得误称商家或顾客实拍。
5. 核验真实珠形/色调、件数、扣型与镶座、身体相对比例、遮挡及重力关系。不确定的长度/尺寸列待确认，不因模特更好看而修改商品事实。

6. 构图按首饰类别和图片用途选择自然身体局部：项链/吊坠以锁骨及领口为背景，耳饰以耳部与侧脸局部展示，手链以自然手腕姿态展示。避免僵直对称摆姿、突兀裁断关节、过度磨皮、分散注意的衣纹/道具；允许合适的浅色衣料与背景，不锁死同一姿势。珠宝是视觉重点但不可夸张放大。

## 证书图：保留事实，只遮识别信息

1. 核对证书属于该产品；保存完整原件在原有私有位置，不覆盖原件、不复制到公开图片目录。缺证书图时标缺失，不借其他产品证书。
2. 对真实证书做可读性整理：摆正、适度去背景和校曝光；保留完整证书内容与四周边缘，不强裁正方形。不得重新生成、描写或重绘任何证书文字、印章、结论或数据；模糊不可读的内容不猜补。
3. 检查所有证书号重复位置，以及能直接或通过查询链接还原号码的条码、二维码。对相关区域全部遮盖；只遮号码而留下能恢复号码的二维码不合格。不能确认编码用途时将相关编码纳入遮盖，避免泄露。
4. 在现有授权及工具规则允许下采用确定性、展平后的遮盖，不只加可移除的显示层；遮挡需要完整覆盖，不保留可辨残码。若无可靠遮号工具，停止公开交付该图，不以生成模型重绘证书来替代。
5. 放大检查全图及每个遮挡边缘，并确认实验室名称、尺寸、检验结果等非识别内容仍与原件一致。OCR/码识别可辅助，但识别失败不等于遮盖合格，不向未授权第三方上传完整证书进行识别。
6. 检查待交付的缩略图、原尺寸、可下载文件，及文件名/alt/公开元数据是否泄号；导出展平遮号副本，公开包只含该副本。若已有公开原图，报告位置，另按用户授权处理，不擅自删历史部署或对象。
7. 使用已批准的证书防盗中英文说明。交付写明“证书已遮号并核验 / 待核验”，未核验不宣称安全。

## 交付检查

每张在内部制作清单记录SKU、原图来源、图片角色、版本、实拍编辑或合成示意、已核验事项及缺口。先给用户看图片；批准后才进入另行授权的网站配置。图片批准不等于允许发布。
